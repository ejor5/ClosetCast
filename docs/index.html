ClosetCast

A closet laptop that watches the yard.

Five RTSP cameras, weather, Apple Calendar, Yankees mode, and afternoon ambiance — fullscreen on an old Windows machine.

View demo GitHub Install

Install on the closet laptop

One PowerShell command downloads ClosetCast, checks Node and FFmpeg, and opens the setup wizard.

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/ejor5/ClosetCast/main/Install-ClosetCast.ps1 | iex"

What it does

  • Five RTSP camera tiles with focus, split, grid, and five-camera layouts
  • Weather, traffic, and up to three Apple Calendar feeds
  • Yankees auto mode and after-noon YouTube ambiance
  • Wind-down reminder and Windows wake/sleep schedule

ClosetCast runs as a local Electron app. The demo uses mock data — no live cameras.
